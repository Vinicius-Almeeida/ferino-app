# 🍕 FERINO - Junta, escolhe e vai!

Protótipo interativo do app FERINO - uma rede social para organizar encontros entre amigos em restaurantes.

![FERINO App](https://img.shields.io/badge/Status-Protótipo-orange)
![React](https://img.shields.io/badge/React-18.2-blue)
![Vite](https://img.shields.io/badge/Vite-5.0-purple)

## 🚀 Demo

Acesse o protótipo: [ferino-app.vercel.app](https://ferino-app.vercel.app)

## ✨ Funcionalidades

### Core
- 👥 Criar grupos privados de amigos
- 📅 Organizar eventos/encontros
- 🗳️ Votação de restaurantes
- 📍 Sugestão de ponto ideal baseado na localização dos participantes
- ✅ Confirmação de presença
- 💬 Chat de grupo

### Social
- 🔍 Buscar e adicionar amigos por @username
- 📸 Grid de fotos no perfil
- 👥 Solicitações de amizade
- 🔔 Notificações

### Extras
- 🗺️ Mapa com restaurantes e localização dos participantes
- ⭐ Favoritar restaurantes
- 🎯 Filtros por tipo de culinária

## 🛠️ Rodar localmente

```bash
# Instalar dependências
npm install

# Rodar em dev
npm run dev

# Build para produção
npm run build
```

## 🚀 Deploy na Vercel

1. Faça push do repositório no GitHub
2. Importe o projeto na [Vercel](https://vercel.com)
3. Deploy automático! ✨
